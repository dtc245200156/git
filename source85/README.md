# Source 85 - Horizontal Dropdown Menu

## Mục tiêu

Luyện tập tạo menu dropdown ngang bằng HTML và CSS.

## Nội dung

Trang thực hành gồm:

- Menu chính hiển thị theo chiều ngang.
- `Sem 1` và `Sem 2` có menu con.
- Các menu con được ẩn mặc định bằng `visibility: hidden`.
- Menu con sử dụng `position: absolute` và được đặt bên dưới menu cha.
- Khi di chuột vào mục cha, menu con hiển thị bằng selector `#menu ul li:hover > ul`.
- Hiệu ứng đổi màu nền liên kết khi hover.
- Responsive cơ bản cho màn hình nhỏ.

## Cấu trúc

```
source85/

```

## Chạy bài

Mở `index.html` bằng WebStorm hoặc trình duyệt. Di chuyển chuột vào **Sem 1** hoặc **Sem 2** để xem menu dropdown ngang.
