# Source 75 - CSS Story Reader

## Mục tiêu

Luyện tập sử dụng HTML và CSS để xây dựng một trang web đọc truyện đơn giản.

## Nội dung thực hành

Trang web gồm:

- Ảnh truyện ở đầu trang.
- Mục lục truyện.
- Nội dung tương ứng với từng mục lục.
- Liên kết nội bộ bằng anchor để click vào mục lục và chuyển tới chương tương ứng.
- Sử dụng thẻ `<h5>` cho từng mục lục truyện.
- CSS để định dạng màu sắc, khoảng cách, đường viền, bố cục và responsive trên màn hình nhỏ.

## Cấu trúc

```
source75/
├── index.html
└── README.md
```

## Chạy bài

Mở file `index.html` bằng WebStorm hoặc trình duyệt để xem trang đọc truyện và thử các liên kết trong mục lục.
