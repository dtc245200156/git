# Source 63 - CSS Selectors

## Mục tiêu

Luyện tập sử dụng các bộ chọn CSS:

- Element selector
- Class selector
- ID selector
- Grouping selector
- Pseudo-class selector

## Nội dung

Trang gồm:

- Tiêu đề `<h1>`: "Trang web của tôi".
- Một đoạn văn giới thiệu bản thân.
- Danh sách 3 sở thích.
- Nút "Nhấn vào đây".

## Bộ chọn đã sử dụng

- **Element:** định dạng `body`.
- **ID:** `#page-title` để căn giữa và đổi màu tiêu đề.
- **Class:** `.container`, `.intro`, `.hobby-list`, `.action-button`.
- **Grouping:** `h1, h2, p`.
- **Pseudo-class:** `.action-button:hover`, `.action-button:active`, `.action-button:focus-visible`.
- **nth-child:** tạo màu khác nhau cho từng sở thích.
