# Source 49 - Hiển thị hình ảnh trong HTML

## Mục tiêu

Luyện tập sử dụng thẻ `<img>` để hiển thị hình ảnh trong trang web và sử dụng thuộc tính `alt` để mô tả hình ảnh.

## Nội dung

- Tạo file `index.html`.
- Sử dụng `<img>` để hiển thị hình ảnh.
- Hình ảnh được đặt trong thư mục `images`.
- Có thuộc tính `alt` mô tả rõ nội dung hình ảnh.
- Hình ảnh có CSS nội tuyến để hiển thị đẹp và tự co giãn theo chiều rộng màn hình.
