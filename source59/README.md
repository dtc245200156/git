# Source 59 - CSS List Properties

## Mục tiêu

Thực hành các thuộc tính danh sách trong CSS:

- `list-style-type`
- `list-style-image`
- `list-style-position`
- `list-style`

## Nội dung

Trang demo gồm:

1. Các kiểu marker của danh sách không có thứ tự và có thứ tự.
2. Marker bằng hình ảnh với `list-style-image`.
3. So sánh `list-style-position: inside` và `outside`.
4. Thuộc tính rút gọn `list-style`.
5. Định dạng màu sắc cho toàn bộ danh sách, marker và từng mục.

## Ghi chú

Hình marker được tạo bằng SVG data URL nên không cần thêm file ảnh bên ngoài.
