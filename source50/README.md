# Source 50 - Simple Order Form

## Mục tiêu

Luyện tập tạo form HTML với các phần tử cơ bản:

- `<form>`
- `<select>` và `<option>`
- Radio button
- Text field
- Email field
- Button submit

## Yêu cầu đã thực hiện

- File chính có tên `simpleform.html`.
- Form dùng `method="get"`.
- Form có `action="simpleform.html"`.
- Font chữ toàn bộ form sử dụng:
  `"Lucida Grande", "Lucida Sans Unicode", Tahoma, sans-serif`.
- Có phần chọn sản phẩm.
- Có lựa chọn số lượng bằng radio button.
- Có FirstName, LastName, Email và Phone Number.
- Có nút Submit.
- Bổ sung CSS bố cục nhẹ và responsive để form dễ quan sát trên màn hình nhỏ.
