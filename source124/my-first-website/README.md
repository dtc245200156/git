# My First Website — About Me

Dự án HTML5 giới thiệu bản thân, được cấu trúc lại bằng Semantic HTML.

## Cấu trúc

- `index.html`: trang giới thiệu bản thân với `header`, `main`, `section` và `footer`.
- `images/profile-avatar.svg`: ảnh đại diện minh họa.
- `observations.md`: ghi chú thực hành và so sánh sau khi dùng Semantic HTML.

## Mở trang

Mở thư mục dự án bằng VS Code và chạy `index.html` với Live Server, hoặc mở trực tiếp tệp bằng trình duyệt.

## Việc cần thay trước khi nộp

1. Thay tên minh họa “Nguyễn Minh Anh” trong `<title>`, `<h1>`, nội dung, thuộc tính `alt` và phần bản quyền bằng tên của bạn.
2. Thay `images/profile-avatar.svg` bằng ảnh cá nhân của bạn và cập nhật `src`/`alt` trong `index.html` nếu tên tệp thay đổi.
3. Thay các liên kết GitHub và Facebook bằng URL hồ sơ cá nhân thực tế.
