# My First Website — Bài tập HTML và External CSS

Dự án thực hành HTML gồm trang giới thiệu bản thân, Semantic HTML, bảng thời khóa biểu, form liên hệ, công thức món ăn và liên kết External CSS.

## Cấu trúc

- `index.html`: trang giới thiệu, dùng Semantic HTML và liên kết đến `style.css`.
- `style.css`: quy tắc CSS bên ngoài; đặt nền trang thành `#f0f8ff` (AliceBlue).
- `timetable.html`: thời khóa biểu tuần với `table`, `thead`, `tbody`, `tr`, `th`, `td`.
- `contact.html`: form liên hệ với `form`, `label`, `input`, `textarea`, `button`.
- `recipe.html`: trang công thức phở gà với `article`, bảng nguyên liệu, danh sách bước nấu và form đánh giá.
- `images/profile-avatar.svg`: ảnh đại diện minh họa cho trang About Me.
- `images/pho-ga.svg`: hình minh họa bát phở gà.
- `observations.md`: ghi chú và tóm tắt các bước thực hành.

## Mở trang

Mở thư mục dự án bằng VS Code và chạy trang HTML cần xem bằng Live Server, hoặc mở trực tiếp tệp bằng trình duyệt. Để kiểm tra External CSS, mở `index.html` và xác nhận nền trang có màu xanh AliceBlue nhạt.

## Lưu ý

- Trang About Me sử dụng tên và ảnh minh họa; hãy thay bằng thông tin cá nhân thật trước khi chia sẻ.
- Các form trong bài tập là giao diện HTML mẫu. Chúng chưa gửi email, lưu bình luận hoặc đánh giá thực sự vì chưa có backend xử lý.
- Hình phở gà là ảnh minh họa SVG tự tạo và được lưu trong thư mục `images`.
