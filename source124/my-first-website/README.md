# My First Website — About Me và Thời khóa biểu

Dự án thực hành HTML gồm trang giới thiệu bản thân, Semantic HTML và một bảng thời khóa biểu cá nhân.

## Cấu trúc

- `index.html`: trang giới thiệu, có `header`, `main`, `section` và `footer`.
- `timetable.html`: thời khóa biểu từ thứ Hai đến thứ Sáu, sử dụng `table`, `thead`, `tbody`, `tr`, `th` và `td`.
- `images/profile-avatar.svg`: ảnh đại diện minh họa.
- `observations.md`: ghi chú thực hành và tóm tắt các bước tạo bảng.

## Mở trang

Mở thư mục dự án bằng VS Code và chạy `index.html` hoặc `timetable.html` với Live Server. Có thể mở trực tiếp các tệp HTML bằng trình duyệt.

## Việc cần thay trước khi nộp trang About Me

1. Thay tên minh họa “Nguyễn Minh Anh” bằng tên của bạn trong tiêu đề, nội dung, thuộc tính `alt` và phần bản quyền.
2. Thay `images/profile-avatar.svg` bằng ảnh cá nhân của bạn và cập nhật đường dẫn `src`/mô tả `alt`.
3. Thay các liên kết GitHub và Facebook bằng URL hồ sơ cá nhân thực tế.
