# Source 93 - Bootstrap Login Form

## Mục tiêu

Thực hành sử dụng **Bootstrap** để xây dựng form đăng nhập đơn giản.

Bài tham chiếu repository CodeGym `jwbd-login-bootstrap` nhánh `develop`, với các tệp `index.html` và `styles.css`.

## Thành phần

- `index.html`: form đăng nhập gồm email, password, Remember me và nút Sign in.
- `styles.css`: căn giữa form, giới hạn chiều rộng 330px, định dạng input và nền trang.
- `bootstrap.svg`: icon Bootstrap cục bộ dùng cho form.

## Bootstrap

Sử dụng Bootstrap 5.0.0-beta2 qua CDN, đúng phiên bản trong bài hướng dẫn.

## Chạy bài

Mở `index.html` bằng trình duyệt có Internet để tải Bootstrap CDN.
