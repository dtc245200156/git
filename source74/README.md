# Source 74 - CSS Text Formatting

## Mục tiêu

Luyện tập sử dụng các thuộc tính CSS để định dạng văn bản.

## Nội dung

Trang HTML thực hành các thuộc tính:

- `font-family`: thiết lập phông chữ.
- `font-size`: thiết lập kích thước chữ.
- `color`: thiết lập màu chữ.
- `text-align`: căn chỉnh văn bản.
- `text-indent`: thụt lề dòng đầu.
- `font-style`: tạo kiểu chữ in nghiêng.
- `line-height`: điều chỉnh khoảng cách giữa các dòng.

Nội dung minh họa gồm tiêu đề **Trời Hà Nội xanh**, thông tin tác giả và hai dòng thơ.

## Chạy bài

Mở file `index.html` bằng WebStorm hoặc trình duyệt để xem kết quả.
