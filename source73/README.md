# Source 73 - CSS Embedding Methods

## Mục đích

Luyện tập nhúng CSS vào trang web bằng 3 cách:

1. Inline CSS
2. Internal CSS
3. External CSS

## Nội dung

Trang `index.html` có 3 phần minh họa:

- **Inline CSS:** dùng thuộc tính `style` trực tiếp trên phần tử HTML.
- **Internal CSS:** dùng thẻ `<style>` trong phần `<head>`.
- **External CSS:** liên kết tới file `style.css` bằng thẻ `<link>`.

Mỗi phần đều có một tiêu đề và một đoạn văn với màu chữ khác nhau để dễ quan sát kết quả.

## Cấu trúc


## Chạy bài

Mở `index.html` bằng trình duyệt hoặc WebStorm để xem kết quả.
