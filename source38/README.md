# Source 38 — Book Landing Page

Trang web tĩnh giới thiệu sách được xây dựng bằng HTML, Bootstrap và CSS.

## Các phần đã triển khai

- Header / Hero
- Book Overview
- Author
- Features
- Prices
- Download
- Reader's Say
- Footer

## Responsive

Sử dụng Bootstrap Grid, Navbar responsive và media query CSS cho desktop, tablet và mobile.

## Công nghệ

- HTML5
- Bootstrap 5
- Bootstrap Icons
- CSS3

## Chạy bài

Mở `index.html` bằng trình duyệt.
