# Source 42 - GitProject

Bài thực hành tổng hợp các thao tác Git/GitHub cơ bản theo yêu cầu:

1. Tạo repository GitProject.
2. Clone repository về máy local.
3. Tạo và commit README.md.
4. Tạo thư mục source.
5. Thêm index.html và news.html.
6. Commit và push thư mục source lên remote.

Do workspace GitHub hiện tại đang sử dụng repository `dtc245200156/git`, phần bài thực hành được lưu trong thư mục `source42/GitProject` để giữ nguyên repository đang được kết nối.

## Cấu trúc bài

    ├── README.md
