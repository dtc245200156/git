# Source 76 - CSS Box Model

## Mục tiêu

Luyện tập sử dụng Box Model trong CSS.

## Nội dung

Trang thực hành sử dụng:

- `border`: tạo và định dạng đường viền cho container và các đoạn văn.
- `background`: tạo màu nền cho trang và nội dung.
- `padding`: tạo khoảng cách giữa nội dung và đường viền.
- `margin`: tạo khoảng cách bên ngoài phần tử và căn giữa container bằng `margin: 0 auto`.
- `width`: thiết lập chiều rộng container.
- Bộ chọn theo `id` để tạo các khoảng cách `margin-bottom` khác nhau cho từng đoạn văn.
