# Source 90 - Newsletter với 2 bộ màu

## Mục tiêu

Bài thực hành xây dựng **2 phiên bản newsletter** từ cùng một cấu trúc Bootstrap, sau đó thay đổi các biến màu để tạo hai phong cách thị giác khác nhau. Nội dung bài yêu cầu sử dụng Adobe Color để khám phá/chọn palette và áp dụng nhất quán vào nền, tiêu đề, nút và các khối nội dung.

Nguồn bài tập được cung cấp trong file markdown của bài nộp: phần mục tiêu yêu cầu luyện tập Adobe Color và áp dụng palette vào các phiên bản newsletter. fileciteturn443file0L3-L16

## Cấu trúc

- `newsletter_version1.html`: phiên bản 1, palette xanh dương + vàng cam.
- `newsletter_version2.html`: phiên bản 2, palette xanh teal + cam.
- `newsletter.css`: CSS dùng chung cho hai phiên bản.

Cả hai phiên bản đều dùng Bootstrap 5.3.3 và giữ khung responsive gồm header, nội dung chính, 2 feature cards và footer, đúng định hướng cấu trúc trong đề bài. fileciteturn443file0L22-L34
