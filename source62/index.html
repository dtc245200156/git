Ba cách nhúng CSS vào trang web

Phần 1: Inline-style

Văn bản này được đổi màu bằng thuộc tính style trực tiếp trên phần tử HTML.

Phần 2: Internal-style

Văn bản này được đổi màu bằng CSS đặt trong thẻ <style> bên trong file HTML.

Phần 3: External-style

Văn bản này được đổi màu bằng CSS từ file style.css bên ngoài HTML.
