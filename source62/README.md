# Source 62 - Ba cách nhúng CSS

## Mục tiêu

Luyện tập nhúng CSS vào HTML bằng ba cách:

1. Inline-style.
2. Internal-style.
3. External-style.

## Nội dung

### Phần 1 - Inline-style

Màu sắc được đặt trực tiếp trên phần tử bằng thuộc tính `style`.

### Phần 2 - Internal-style

Màu sắc được đặt trong thẻ `<style>` bên trong phần `<head>` của file HTML.

### Phần 3 - External-style

Màu sắc được đặt trong file `style.css` riêng và liên kết vào HTML bằng:

```html
<link rel="stylesheet" href="style.css">
```
