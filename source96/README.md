# Source 96 — Bootstrap Surface Landing Page

Bài tập luyện tập Bootstrap bằng cách dựng một Landing Page lấy cảm hứng từ trang Microsoft Surface.

## Nội dung

- Navbar responsive với Bootstrap.
- Hero Carousel với nút điều hướng.
- Grid Bootstrap cho nhóm tiện ích và sản phẩm.
- Card, Badge, Button, Accordion và Footer.
- Responsive bằng utility classes và grid của Bootstrap.
- CSS tự viết được giữ ở mức tối thiểu cho hero, tỷ lệ ảnh và khoảng cách lớn.
- Hình ảnh sản phẩm/lifestyle được tham chiếu từ các asset hiển thị trên trang Microsoft Surface.

## Công nghệ

- HTML5
- Bootstrap 5.3.3 CDN
- Bootstrap Icons 1.11.3
- CSS3

## Chạy bài

Mở file index.html bằng trình duyệt có kết nối Internet để tải Bootstrap và các hình ảnh từ CDN/asset của Microsoft.

Tham khảo mẫu: https://www.microsoft.com/en-us/store/b/surface
