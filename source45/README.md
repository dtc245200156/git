# Source 45 - Tiêu đề và đoạn văn trong HTML

## Mục tiêu

Luyện tập sử dụng các thẻ tiêu đề và đoạn văn cơ bản trong HTML.

## Nội dung

- `<h1>`: tiêu đề chính với nội dung "Chào mừng đến với trang web của tôi".
- `<h2>`: tiêu đề phụ với nội dung "Giới thiệu bản thân".
- Hai thẻ `<p>`: mô tả sở thích cá nhân và mục tiêu học lập trình.
