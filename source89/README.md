# Source 89 - Phối màu đơn tông cho trang web

## Mục tiêu

Thực hành phối lại màu cho một trang web theo nguyên tắc màu đơn tông (monochromatic).

Bài thực hành tham chiếu hướng dẫn CodeGym về việc dùng màu xanh logo #00ADEE làm màu bậc 1, sau đó giảm dần độ nhạt để thay đổi các khu vực của trang.

## Phiên bản 1 - Blue Monochromatic

index.html sử dụng bố cục web bán sản phẩm và áp dụng các màu theo yêu cầu:

| Khu vực | Màu |
|---|---|
| Màu chủ đạo / bậc 1 | #00ADEE |
| Banner ON SALE / PREVIEW | #00B2EF |
| Nền trang | #00BFF2 |
| Nền phần nội dung | #8DD7F7 |
| Footer | #C6E9FA |
| Typography | #000000 |
| Chữ trên nền đậm | #FFFFFF |

Bố cục gồm header, hero, ON SALE/PREVIEW, khu vực sản phẩm, phần giải thích hệ màu và footer.

## Phiên bản 2 - Purple Monochromatic

alternate.html thực hiện bước mở rộng: giữ nguyên logic phối màu nhưng tạo một hệ màu đơn tông khác:

#5B21B6 → #6D28D9 → #7C3AED → #8B5CF6 → #A78BFA → #C4B5FD → #DDD6FE → #EDE9FE → #F5F3FF

Trang này minh họa cách thay toàn bộ bảng màu mà vẫn giữ nguyên cấu trúc và nguyên tắc phân cấp màu.

## Chạy bài

Mở index.html hoặc alternate.html trực tiếp bằng trình duyệt để xem kết quả.
