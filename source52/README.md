# Source 52 - Bảng đơn giản trong HTML

## Mục tiêu

Luyện tập tạo bảng cơ bản trong HTML để hiển thị dữ liệu có cấu trúc.

## Thẻ đã sử dụng

- `<table>`: tạo bảng.
- `<tr>`: tạo một hàng.
- `<th>`: tạo ô tiêu đề.
- `<td>`: tạo ô dữ liệu.

## Nội dung bảng

Bảng hiển thị danh sách học sinh với các cột:

- Họ và Tên
- Tuổi
- Lớp

Có 3 học sinh mẫu theo yêu cầu đề bài.
