# Source 57 - Danh sách sản phẩm

## Mục tiêu

Luyện tập sử dụng bảng HTML với các thẻ:

- `<table>`
- `<tr>`
- `<th>`
- `<td>`

## Nội dung

Trang web có tiêu đề **Danh sách sản phẩm** và một bảng gồm 3 cột:

- Tên sản phẩm
- Giá
- Số lượng

Bảng có 4 sản phẩm mẫu.
