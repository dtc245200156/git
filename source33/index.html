SASS CLI & NPM

Luyện tập biên dịch SCSS sang CSS

Trang thực hành minh họa cách viết SCSS, sử dụng biến, mixin và nesting, sau đó biên dịch thành CSS bằng Sass CLI.

Quy trình Sass

01

Kiểm tra Node.js

Chạy node -v và npm -v trong Terminal để kiểm tra môi trường.

02

Cài đặt Sass

Sử dụng npm install để cài Sass cho dự án.

03

Biên dịch

Chuyển SCSS thành CSS và dùng watch mode để tự động cập nhật.

CLI COMMAND

SCSS → CSS

File main.scss là entry point. CSS đầu ra được tạo trong thư mục css. 

npm install
npm run sass
npm run watch

Các khái niệm đang sử dụng

$variables Quản lý màu sắc và khoảng cách.
@mixin Tái sử dụng nhóm quy tắc CSS.
Nesting Giúp SCSS dễ đọc và dễ tổ chức.
Watch Tự động biên dịch khi file thay đổi.
