# Source 83 - Fixed Menu

## Mục tiêu

Luyện tập tạo Fixed Menu bằng CSS và hiểu cách sử dụng `position: fixed`.

## Nội dung

Trang thực hành gồm:

- Thanh menu cố định ở phía trên bằng `position: fixed`.
- `top: 0` để đặt menu ở mép trên trình duyệt.
- `width: 100%` để menu kéo dài toàn bộ chiều ngang.
- Các liên kết `Home`, `News`, `Contact`, `About` liên kết tới từng khu vực trên trang.
- Nội dung đủ dài để kiểm tra hiệu ứng khi cuộn.
- Responsive cho màn hình nhỏ.

## Chạy bài

Mở `index.html` bằng WebStorm hoặc trình duyệt, sau đó cuộn trang để kiểm tra menu luôn cố định ở phía trên.
