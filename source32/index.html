GIỚI THIỆU

Chia nhỏ code để phát triển dự án dễ dàng hơn.

Sass cho phép tách phần cấu hình, bố cục, component và page-specific styles thành các file riêng, sau đó gộp lại thông qua file chính.

CẤU TRÚC

Bảy khu vực chính của dự án Sass

Abstracts

Variables, mixins, functions.

Base

Reset, typography, global rules.

Layout

Header, footer, grid.

Components

Buttons, cards and reusable UI.

Pages

Styles specific to each page.

Themes

Light and dark visual themes.

Vendors

Third-party styles and overrides.

MAIN.SCSS

Một file chính để kết nối toàn bộ hệ thống.

File main.scss import các partial theo đúng nhóm, giúp developer dễ tìm file cần sửa và dễ mở rộng dự án sau này. 

$ sass/
├── abstracts/
├── base/
├── layout/
├── components/
├── pages/
├── themes/
└── vendors/

main.scss
