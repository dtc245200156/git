# Source 72 - CSS Properties Practice

## Mục tiêu

Luyện tập sử dụng các thuộc tính CSS để thay đổi cách hiển thị của phần tử HTML.

## Nội dung thực hành

File `index.html` thực hiện các bước:

1. Tạo tiêu đề `h1` và các đoạn văn `p`.
2. Sử dụng `font-family` để thay đổi kiểu chữ.
3. Sử dụng `color` và `font-size` để thay đổi màu sắc, kích thước chữ.
4. Sử dụng `border` để tạo đường viền cho thẻ `p`.
5. Sử dụng `padding` để tạo khoảng cách giữa nội dung và đường viền.
6. Gán `id="element1"` cho một phần tử để áp dụng CSS riêng bằng bộ chọn `#element1`.

## Chạy bài

Mở file `index.html` bằng WebStorm hoặc trình duyệt để xem kết quả.
