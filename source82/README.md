# Source 82 - Cartoon Video Website Layout

## Mục tiêu

Luyện tập:

- Tạo layout bằng `div` và CSS.
- Sử dụng thẻ `<video>`.
- Nhúng YouTube bằng `<iframe>`.
- Tạo header cố định.
- Thiết kế giao diện responsive.

## Chức năng

Trang mô phỏng một website xem phim hoạt hình với:

- Header cố định phía trên.
- Thanh liên kết danh mục.
- Sidebar trái chứa danh sách phim.
- Khu vực nội dung bên phải hiển thị video được chọn.
- Video HTML5 bằng thẻ `<video>`.
- Video YouTube bằng thẻ `<iframe>`.
- Ô tìm kiếm phim theo tên.
- Responsive trên tablet và mobile.
