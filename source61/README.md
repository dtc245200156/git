# Source 61 - Trang Web Cá Nhân

## Mục tiêu

Luyện tập nhúng CSS vào HTML, sử dụng bộ chọn CSS, border, background-color, background-image và color để xây dựng một trang web cá nhân.

## Nội dung

Trang gồm:

1. Tiêu đề chính.
2. Ảnh đại diện local.
3. Giới thiệu bản thân.
4. Danh sách sở thích.
5. Mục tiêu học tập.
6. Bảng thông tin liên hệ.

## CSS đã áp dụng

- Kết nối file `style.css` bằng thẻ `<link>`.
- Bộ chọn phần tử, class và pseudo-state.
- `border`, `border-radius`, `outline`.
- `background-color` và `background-image`.
- `color`, `box-shadow`, typography.
- Responsive layout với media query.

## Ghi chú

Ảnh đại diện được tạo dưới dạng SVG local để bài chạy ngay mà không phụ thuộc vào ảnh bên ngoài. Thuộc tính `alt` trong HTML mô tả nội dung ảnh.
