Web Technology

HTML là ngôn ngữ đánh dấu được sử dụng để xây dựng cấu trúc của trang web. HTML giúp trình duyệt hiểu cách hiển thị văn bản, hình ảnh, liên kết và nhiều nội dung khác theo một cấu trúc rõ ràng.

C Programming

C là ngôn ngữ lập trình thủ tục được sử dụng rộng rãi trong lập trình hệ thống. C cung cấp khả năng truy cập bộ nhớ ở mức thấp, cú pháp gọn và phù hợp cho việc xây dựng hệ điều hành, trình biên dịch và nhiều chương trình hiệu năng cao.

Java

Java là một ngôn ngữ lập trình hướng đối tượng phổ biến. Mã Java thường được biên dịch thành bytecode và chạy trên Java Virtual Machine (JVM), giúp chương trình có thể hoạt động trên nhiều kiến trúc khác nhau.
