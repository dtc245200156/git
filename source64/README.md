# Source 64 - Background Color & Background Image

## Mục tiêu

Luyện tập sử dụng CSS `background-color` và `background-image` để thiết kế trang web.

## Nội dung

Trang gồm:

- Tiêu đề `<h1>` với nội dung "Chào mừng đến với trang web của tôi".
- Một đoạn văn mô tả trang web.
- Một khối `<div>` chứa nội dung quan trọng.
- Màu nền cho toàn bộ trang bằng `background-color`.
- Ảnh nền cho khối nội dung bằng `background-image`.
- Nội dung bên trong khối được căn giữa bằng Flexbox.

## CSS đã sử dụng

- `background-color`
- `background-image`
- `background-size: cover`
- `background-position: center`
- `display: flex`
- `align-items: center`
- `justify-content: center`

Ảnh nền được tạo dưới dạng SVG data URL nên bài không phụ thuộc file ảnh bên ngoài.
