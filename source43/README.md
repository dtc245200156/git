# Source 43 - Định dạng văn bản bằng HTML

## Mục tiêu

Luyện tập sử dụng các thẻ định dạng văn bản và thuộc tính CSS nội tuyến (`style`).

## Nội dung đã thực hành

- `<h1>`: tạo tiêu đề chính.
- `<p>`: tạo đoạn văn bản.
- `<b>`: chữ in đậm.
- `<i>`: chữ in nghiêng.
- `<u>`: chữ gạch chân.

## CSS nội tuyến

- `color`: thay đổi màu chữ.
- `font-size`: thay đổi kích thước chữ.
- `text-align`: căn chỉnh văn bản.
- `font-family`: thiết lập font chữ.
- `font-weight`: điều chỉnh độ đậm.

## Kết quả

Trang web hiển thị các đoạn văn bản với nhiều kiểu định dạng khác nhau, đồng thời sử dụng CSS nội tuyến trực tiếp trên các phần tử HTML theo yêu cầu bài tập.
