# Source 48 - CSS nội tuyến

## Mục tiêu

Luyện tập sử dụng thuộc tính CSS nội tuyến `style` để định dạng văn bản trong HTML.

## Nội dung đã thực hành

- Tiêu đề `<h1>` màu xanh dương.
- Đoạn văn `<p>` màu đỏ và in đậm.
- Đoạn văn `<p>` in nghiêng và căn giữa.
- Đoạn văn `<p>` có cỡ chữ 20px và gạch chân.

## Các thuộc tính CSS sử dụng

- `color`
- `font-weight`
- `font-style`
- `text-align`
- `font-size`
- `text-decoration`
