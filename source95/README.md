# Source 95 - Bootstrap Responsive Gallery

## Mục tiêu

Luyện tập sử dụng **Bootstrap Grid System** để xây dựng gallery ảnh responsive.

## Yêu cầu đã thực hiện

Mỗi ảnh sử dụng cùng cấu trúc:

`col-12 col-sm-6 col-lg-3`

Kết quả responsive:

- **Desktop (lg):** 4 ảnh trên một dòng.
- **Tablet (sm):** 2 ảnh trên một dòng.
- **Mobile:** 1 ảnh trên một dòng.

## Bootstrap

Sử dụng Bootstrap 5.3.3 qua CDN với các thành phần:

- `container`
- `row`
- `col-12`
- `col-sm-6`
- `col-lg-3`

## Chạy bài

Mở `index.html` bằng trình duyệt có kết nối Internet để tải Bootstrap và ảnh gallery.
