# Source 79 - HTML5 Semantic Layout

## Mục tiêu

Luyện tập thiết kế bố cục trang web bằng các thẻ semantic của HTML5 kết hợp với CSS.

## Các thẻ semantic sử dụng

- `header`: phần đầu trang.
- `nav`: menu điều hướng.
- `main`: nội dung chính.
- `section`: các khu vực nội dung.
- `article`: từng bài viết độc lập.
- `aside`: nội dung phụ và danh mục.
- `footer`: phần chân trang.

## Nội dung bài

Trang được thiết kế theo bố cục cơ bản:

- Header ở phía trên.
- Navigation menu ngay bên dưới.
- Khu vực nội dung chính gồm các section và article.
- Sidebar dùng thẻ `aside`.
- Footer ở cuối trang.
- CSS Grid được sử dụng để chia khu vực nội dung chính và sidebar.
- Có responsive cơ bản trên màn hình nhỏ.
