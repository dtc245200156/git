# Source 80 - Facebook Layout Practice

## Mục tiêu

Luyện tập thiết kế giao diện mạng xã hội đơn giản với:

- Fixed header.
- Sidebar.
- Nội dung chính.
- Bố cục nhiều cột và responsive.

## Nội dung

Trang mô phỏng giao diện Facebook gồm:

- **Fixed header:** luôn cố định ở phía trên bằng `position: fixed`.
- **Left sidebar:** thông tin cá nhân và menu điều hướng.
- **Main content:** stories, khung tạo bài viết và các bài đăng.
- **Right sidebar:** danh sách người liên hệ và sự kiện.
- **Responsive:** tự động ẩn sidebar phải và chuyển bố cục sang một cột trên màn hình nhỏ.
