# Source 92 - Vịnh Hạ Long - Kỳ quan Thiên nhiên

## Mục tiêu

Thực hành HTML cơ bản với các thẻ:

- `<h1>` cho tiêu đề chính.
- `<p>` cho các đoạn văn.
- `<img>` với `src`, `alt`, `width`.
- `<a>` để tạo liên kết đến Wikipedia.

## Tệp

- `halong_bay.html`: trang HTML hoàn chỉnh theo giải pháp mẫu của bài tập.

## Nội dung

Trang gồm tiêu đề Vịnh Hạ Long, hai đoạn mô tả, một hình ảnh minh họa và liên kết Wikipedia về Vịnh Hạ Long.

## Chạy bài

Mở trực tiếp `halong_bay.html` bằng trình duyệt web.
