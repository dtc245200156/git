# Source 51 - Form tìm kiếm\n\n## Mục tiêu\n\nThực hành gửi dữ liệu từ HTML form lên server bằng phương thức GET.\n\n## Form Google\n\nForm chính sử dụng action là https://www.google.com.vn/search, method GET và input có name=q.\n\nVí dụ URL sau khi tìm kiếm:\n\nhttps://www.google.com.vn/search?q=html\n\nÝ nghĩa:\n- action: URL nhận dữ liệu của form.\n- method=GET: dữ liệu được gửi dưới dạng query string và xuất hiện trong URL.\n- name=q: tên tham số chứa từ khóa tìm kiếm.\n\n## Tìm kiếm bằng Bing\n\nĐổi action thành https://www.bing.com/search và vẫn dùng input name=q.\n\n## GET và POST\n\nGET gửi dữ liệu dưới dạng query string trong URL, phù hợp với tìm kiếm hoặc truy vấn có thể chia sẻ bằng URL.\n\nPOST gửi dữ liệu trong phần body của HTTP request và không hiện trực tiếp trong URL. POST không tự động làm dữ liệu an toàn; dữ liệu nhạy cảm vẫn cần HTTPS và các biện pháp bảo mật phù hợp.\n\n## Cấu trúc\n\nsource51/\n├── index.html\n└── README.md
